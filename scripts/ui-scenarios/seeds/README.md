# Seeders for the 2026-10-05 be-the-user scenarios

The `xa-` to `xk-` scenarios were written by explorer agents against GreenMail
accounts they seeded themselves. The scripts they used are kept here, one folder
per journey prefix, copied from `build/explore/<prefix>/` as they were. Run the
seeder for a prefix before its scenarios on a fresh GreenMail container.
Scenarios under `../pending-defects/` fail on purpose: each is the gate for a
confirmed defect and moves back up with its fix.
