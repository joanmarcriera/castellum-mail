Reading messages: unsubscribe, invites, trust and attachments

Reading pane · Castellum

1. Unsubscribe

When a message offers a standard unsubscribe option, an Unsubscribe button appears in the reading pane. Castellum never unsubscribes on its own and never opens a link automatically. It first shows you exactly where the request would go:

  • For a one-click list, it sends a single request to the address shown, and nothing else leaves your Mac.
  • For an email-based list, it creates and sends a short email to the address shown.

You confirm in both cases, or cancel.

2. Calendar invites

A message with a calendar invitation shows a card with the event. Accept, Decline and Maybe send an ordinary reply, queued and sent like any other message. They appear only for real invitations, not for cancellations or plain calendar attachments. Add to Calendar puts the event in your Calendar; macOS asks for Calendar permission the first time you use it, and the replies work without it.

3. The trust shield

A small shield on the message shows what the receiving server recorded when it checked the message (SPF, DKIM and DMARC):

  • Plain shield: nothing was verified. This is common and not a warning; many personal and small-business servers do not record checks.
  • Shield with a tick: the checks that ran passed.
  • Amber shield: a check failed. Be careful with links and attachments.

4. Remote images

Remote images are blocked by default, because loading them can tell the sender when you read the mail. A bar says Remote images blocked with Load for this message, or Always allow this sender. Change the default or revoke senders in Settings > General.

5. Attachments

Attachments sit in a strip under the header. You can open them, save them or preview them with Quick Look; choose what a click does in Settings > General > Attachments.

6. Message source and printing

View > Message Source (⌥⌘U) opens the raw message with all its headers; ⌘F searches inside it. File > Print… (⌘P) prints the open message.
