Managing accounts

Settings > Accounts · Castellum

Adding an account is covered in Connect any account. Everything you do with an account afterwards is in Settings > Accounts. Select an account in the list, then use the buttons underneath. On a narrow window the last three sit under a More menu.

1. What the list shows

Each row shows the address, the server it talks to, when it last synced (or the last error), and whether it is read-only or has writes enabled. A footer summarises how many accounts are read-only. Your passwords are kept in the macOS Keychain, not in the list.

2. Add…

Opens the same sheet as the + button in the main window toolbar.

3. Re-authenticate…

Use this when a password stops working, for example after you revoke or replace an app password. It reopens the sign-in sheet for the same account, so your mail and settings stay where they are. Enter the new password and save.

4. Folders…

Choose which folders this account syncs, and how far back to go. Castellum asks your server for its current folder list, with today's choices ticked. If the server cannot be reached, the sheet shows your saved choice read-only, and you can still change how far back to sync. Saving does not touch your password and does not start a sync by itself.

5. Duplicate…

Starts adding a new account with the settings of the selected one already filled in. Useful for a second mailbox on the same provider. It creates a separate account; it does not copy any mail.

6. Reset…

Wipes this account's locally-synced mail, downloaded attachments, drafts, sync state and AI summaries from this Mac, then syncs again from the server. Kept: the saved password, the server settings and the signature. Nothing on the mail server changes. If the account still has unsent drafts or changes waiting to go to the server, Castellum warns you first (Still Sending); Discard and Reset throws them away, and a message still sending will not be delivered. Reset cannot be undone.

7. Remove…

Permanently deletes the account's locally-synced mail, drafts and queued sends from this Mac, and removes its saved password from the Keychain. Nothing on the mail server is deleted. Removing cannot be undone.
