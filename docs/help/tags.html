Tags

Message > Tag… · Settings > Tags · Castellum

Tags are labels you attach to messages. They are stored on your mail server as standard IMAP keywords, so they sync with the server.

Tagging needs writes enabled. A tag is a change to the message on the server, so an account that is still read-only will refuse it.

1. Tag a message

Select a message and press l (the letter L, as in “label”), or ⌥⌘T, or choose Message > Tag…. Pick a tag from the list, or choose New Tag… to make one. Choosing a ticked tag removes it. With several messages selected, a tag is added to all of them if any one lacks it.

Find tagged mail with the tag: search operator (see Searching mail), or a Tag condition in a Smart Mailbox.

2. Manage tags

Open Settings > Tags. You can rename a tag, change its colour, drag tags to reorder them, and delete one. Deleting a tag only deletes its name and colour in Castellum: messages keep the keyword on the server.

3. Keywords already on your server

Under the list, Castellum shows keywords that exist on your servers but that you have not named here yet, so you can adopt them as tags.
