Import, export, Delete and Trash

File menu · Message menu · Castellum

1. Export a message as .eml

Select a message and choose File > Export as .eml…. Pick where to save it. With several messages selected, you choose a folder and each becomes its own file. File names start with the date, followed by the subject, with characters that are unsafe in file names replaced and the length kept sensible. If a name is taken, a number is added.

2. Import .eml files

Select a mailbox and choose File > Import…, then pick one or more .eml files. They are added to that mailbox: Castellum queues them and uploads them to your mail server in the background. A file that cannot be read is reported and the others still import.

3. Delete

Delete (# or ⌘⌫) moves the message to Trash, and you can still get it back. The exception is inside Trash itself: there, Delete removes the message for good, and only after a dialog that says it cannot be undone. If your selection mixes Trash and other mailboxes, it is a normal move to Trash.

4. Empty Trash

Message > Empty Trash… permanently erases everything in one account's Trash, after a confirmation that names the account. It needs a single account to be selected, so choose a mailbox first.

5. Archive

Archive (e or ⌘E) moves the message out of the Inbox into the account's Archive.

These actions change the mail server, so an account must have writes enabled.
