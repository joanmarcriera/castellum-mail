Keyboard shortcuts

Help > Keyboard Shortcuts · Castellum

Castellum is built to be used from the keyboard. Press ? or ⌘/ at any time to open the same list inside the app (Help > Keyboard Shortcuts). You can change any of these: see Custom key bindings. The command palette finds any command by name.

Single keys only work in the message list. Keys like e and j act when the message list has focus. They do nothing while you are typing in the search field or a compose window. Letters are not case-sensitive, except where a capital is listed: R (reply all) and B (un-snooze) mean Shift plus the letter.

Archive, Delete and Mark All as Read are treated as destructive: their shortcuts do not fire from the menu bar while a text field has focus. On an account that is still read-only, actions that change the server are refused.
