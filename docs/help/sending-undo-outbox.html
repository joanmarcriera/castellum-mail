Sending: Undo Send, Send Later and the Outbox

Settings > General > Sending · Message > Outbox · Castellum

Sending in Castellum is queued, so a slow connection or a closed lid never loses a message.

Sending needs writes enabled. On an account that is still read-only, Send is refused with a dialog; if you enable writes from that dialog, Castellum sends the message straight away.

1. Undo Send

After you click Send, a banner appears at the bottom of the main window with a live countdown and an Undo button. It does not block anything else. Click Undo (or press ⌘Z) before the countdown ends and the message reopens, unsent, in a compose window. If it is too late, the banner says so.

Choose the delay in Settings > General > Sending > Undo send: Off, 5, 10, 20 or 30 seconds. The default is 10. With Off, Send goes out straight away.

2. Send Later

In a compose window press ⌥⌘L (or choose Message > Send Later…) and pick a time.

A scheduled message waits in the Outbox, and Castellum checks every 15 seconds whether one is due.

3. The Outbox

Choose Message > Outbox to see everything waiting to reach the server: scheduled messages, messages waiting to send, and changes that failed. For each you can Retry or Cancel; for waiting messages, Send Now, Edit and Reschedule. Cancel All… asks for confirmation. Message > Send All Waiting Messages (⇧⌘D) sends every waiting message immediately. When something is waiting, the sidebar also shows an Outbox entry with a count.

4. Forgotten attachment warning

If your message mentions an attachment (for example “attached”, “adjunto” or “adjunt”) but nothing is attached, Castellum asks before sending. Turn this off in Settings > General > Sending with Warn when a message mentions an attachment but has none.
