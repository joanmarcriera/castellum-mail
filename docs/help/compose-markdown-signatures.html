Composing: Markdown, signatures and identities

Compose window · Settings > Accounts · Castellum

1. Markdown mail

Tick Markdown in the compose window to write in Markdown. Castellum sends the message in two parts: a nicely styled HTML copy, and a plain-text copy that is your Markdown exactly as you typed it, so every reader sees something readable.

  • Theme. With Markdown on, a Theme menu picks how the HTML copy looks: Plain (no styling), Clean, Serif or Compact. The starting theme is set in Settings > General > Markdown mail; each message can override it.
  • Per-account default. In Settings > Accounts, select an account and tick New messages from … start as Markdown to have new messages start with Markdown on.

2. Signatures

An account can have several signatures. In Settings > Accounts, select an account and click Signatures…. In the Signatures window:

  • The Account menu at the top chooses whose signatures you are editing.
  • Use + and − under the list to add and remove signatures, and Set as Default to choose the one new messages start with.
  • Give each a Name, and switch the editor between Plain Text and HTML.

In a compose window, the Signature menu at the bottom lets you choose a different signature for that message.

3. Identities (send as another address)

An identity is an extra address you can send from on the same account, such as an alias. In Settings > Accounts, select the account, then under Identities click Add Identity…. Enter the email address and, if you like, a display name, a Reply-To address, and an address to Bcc on every message. Tick Use for new messages from this account to make it the default. Your mail provider must also allow sending from that address.

In a compose window, a Send As menu appears once the account has identities. Use Edit… or Remove beside an identity to change it; removing asks for confirmation.
