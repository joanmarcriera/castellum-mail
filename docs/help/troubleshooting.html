Status, Diagnostics and support bundles

Window > Status · Help > Diagnostics · Castellum

Two windows help when mail is not arriving or something looks wrong.

1. Status

Window > Status is a one-screen health check. Each account shows its sync state, when it last synced, the kind of the last error if there was one, and the IMAP and SMTP servers it uses. Further sections show whether AI is reachable, what is in the Outbox, and when Castellum last checked for updates (with a Check for Updates… button).

2. Diagnostics

Help > Diagnostics goes deeper, per account and mailbox: last sync, message counts, messages missing their body, and a Performance section with the timings of the latest sync. Run Database Check tests the local database for problems. This window shows your real address and folder paths, because it stays on your Mac.

3. Gather Diagnostics…

If you need to ask for help, click Gather Diagnostics… in the Diagnostics window. It always produces a redacted bundle: app and macOS versions, provider capabilities, anonymised sync counters and error categories, a short app-log excerpt, and recent Castellum crash reports, with addresses, message content and credentials removed. Provider capabilities are limited to a fixed list of known names; anything else is reported only as “OTHER”.

Nothing is sent anywhere. You choose where to save the bundle and can attach it to an email yourself.

4. Common first checks

  • Archive or Delete does nothing: the account is probably read-only.
  • Cannot connect: IMAP must use port 993 with TLS. Castellum does not support port 143 or STARTTLS for IMAP. See Connect any account.
  • Password stopped working: use Re-authenticate… in Settings > Accounts.
  • Outlook or Microsoft 365: not supported yet; see the connect page.
  • AI does not respond: see AI help and use Test Connection.

You can also file an issue.
