Split Inbox tabs

Smart Mailboxes · View menu · Castellum

A split divides your Inbox into tabs, so the mail that matters is not buried under the rest.

1. What a split is

A split is a Smart Mailbox built from conditions, with one extra switch turned on: Show as a tab in the Inbox. Once at least one split exists, your Inbox shows a row of tabs.

2. Create one

  1. Click the save-search button in the toolbar, give it a name (for example “Newsletters”), and open the Conditions tab.
  2. Set the conditions, for example Subject contains “newsletter”.
  3. Turn on Show as a tab in the Inbox, and save.

Edit it later the same way as any Smart Mailbox: right-click it in the sidebar and choose Edit…. Turn the switch off to remove the tab.

3. How messages are sorted

Each Inbox message goes into the first split it matches. A message that matches none of them goes into Other. A message never appears in two tabs. Each tab shows its count of messages.

4. Where the tabs appear

Tabs appear in a single account's Inbox and in All Inboxes. They do not appear in other mailboxes. Each tab lists up to 500 messages and does not load more.

5. Moving between tabs

Choose View > Next Split or Previous Split, or press ⇧⌘] and ⇧⌘[.
