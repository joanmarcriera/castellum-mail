Command palette

View > Command Palette · Castellum

The command palette lets you run any command without remembering where it lives or what its shortcut is.

1. Open it

Press ⇧⌘K, or choose View > Command Palette….

2. Find a command

Start typing. The matching is forgiving: the letters you type just have to appear in the command's name in that order, so arc finds Archive and nwm finds New Message. Matches at the start of a word rank higher. With nothing typed, the palette lists every command.

Each row shows the command's name and, on the right, its keyboard shortcut if it has one. That makes the palette a good way to learn the shortcuts.

3. Run it

Use the arrow keys to move through the results and press Return to run the highlighted command, or click it. Press Esc to close the palette without doing anything.

4. Greyed-out commands

A command that cannot run right now is shown dimmed and cannot be chosen. For example, Reply needs a message with its body loaded, Archive and Delete need a selected message, and Reply with AI also needs AI switched on.
